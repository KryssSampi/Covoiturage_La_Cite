Moteur de Matching — Formule Complète

MatchingEngineService.ComputeScore(Trip trip, User passenger, UserPreferences prefs)
Calcul du score de compatibilité 0–100 entre un passager et un trajet publié. Exécuté en C#, résultat mis en cache Redis 10 minutes. 5 critères pondérés + bonus/malus.
// ─── Critère 1 : Proximité Départ (poids 35%) ───────────────────────────────
DepartureProximity = ST_Distance(passenger.HomePoint, trip.DeparturePoint)  // PostGIS
DepartureScore = distance_m ≤ 500  → 35 pts
               | distance_m ≤ 1000 → 30 pts
               | distance_m ≤ 2000 → 25 pts
               | distance_m ≤ 5000 → 15 pts
               | distance_m ≤ 10000→  5 pts
               | else              →  0 pts

// ─── Critère 2 : Proximité Arrivée (poids 30%) ──────────────────────────────
ArrivalScore    = distance_m ≤ 500  → 30 pts
               | distance_m ≤ 1000 → 25 pts
               | distance_m ≤ 2000 → 20 pts
               | distance_m ≤ 5000 → 10 pts
               | else              →  0 pts

// ─── Critère 3 : Horaire (poids 15%) ────────────────────────────────────────
TimeDeltaMin    = |prefs.DesiredTime - trip.DepartureTime|
ScheduleScore   = delta ≤ 15 → 15 pts | ≤ 30 → 12 | ≤ 60 → 8 | ≤ 120 → 4 | else → 0

// ─── Critère 4 : Compatibilité Préférences (poids 10%) ──────────────────────
PreferenceScore = 0
IF trip.MusicAllowed  == prefs.MusicAccepted     THEN += 2
IF trip.PetsAllowed   == prefs.HasPets           THEN += 2
IF trip.SmokingAllowed== prefs.SmokesRegularly   THEN += 2
IF trip.BaggageAllowed>= prefs.TypicalBaggage    THEN += 2
IF trip.ConversLevel  == prefs.ConversationLevel  THEN += 2   // max 10

// ─── Critère 5 : Affinité Historique (poids 10%) ────────────────────────────
Affinity        = affinities WHERE userId=passenger AND targetId=driver
AffinityScore   = tripsTogther = 0 →  0 | ≤ 2 →  3 | ≤ 5 →  5 | ≤ 10 →  8 | > 10 → 10
IF affinity.IsActuallyFavorite THEN += 5   // bonus favori hors plafond

// ─── Bonus / Malus ───────────────────────────────────────────────────────────
Bonuses = 0
IF driver.IsProfileVerified            THEN += 5
IF driver.AverageRating > 4.5          THEN += 3
IF driver.PunctualityScore > 95        THEN += 2
IF driver.AverageRating < 3.5          THEN -= 5
IF driver.CancellationRate > 0.10      THEN -= 5
IF affinity.HadIncident                THEN -= 15
IF affinity.IsBlocked                  THEN = ELIMINATE (return -1)
IF passenger.GoScore < prefs.MinGoScore THEN = ELIMINATE (return -1)

// ─── Score Final ─────────────────────────────────────────────────────────────
GlobalScore = DepartureScore + ArrivalScore + ScheduleScore 
            + PreferenceScore + AffinityScore + Bonuses
GlobalScore = Math.Clamp(GlobalScore, 0, 100)

// Badges visuels selon score
≥ 90 → "🏆 Meilleur Match"   | ≥ 80 → "⭐ Excellent Match" | ≥ 70 → "✅ Bon Match"
